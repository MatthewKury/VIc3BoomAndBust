# ============================================================
#  Boom & Bust — Society Tech Overrides (early-load shadow)
#
#  The tech database is FIRST-read-wins: files load in ASCII
#  filename order across vanilla + mods, and duplicate keys in
#  later files are discarded. This file sorts before vanilla
#  30_society.txt, so these three copies win and vanilla logs
#  three harmless "Duplicated key X will not be created from
#  file: .../30_society.txt" lines at every launch — expected.
#
#  Each tech is a full copy of its vanilla 1.13 definition plus
#  one "# BB:" tagged line: the Bureau of Market Relations
#  max-investment modifier (works because the institution key
#  starts with "institution_" — see bb_institutions.txt).
#  The engine max is the plain SUM of these modifiers (no
#  implicit base 1; the game only min-clamps the level to 1).
#  Cap ladder:
#    stock_exchange           (era 1) +1 -> cap 1 (institution
#                                     becomes properly investable)
#    corporate_charters       (era 2) +1 -> cap 2
#    philosophical_pragmatism (era 3) +1 -> cap 3
#    macroeconomics           (era 5) +2 -> cap 5 (endgame jump)
#
#  PATCH SENSITIVITY: only these four techs are masked. After
#  a game patch, re-diff these blocks against vanilla
#  30_society.txt and re-apply any upstream changes.
# ============================================================
